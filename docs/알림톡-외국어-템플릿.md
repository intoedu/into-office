# 외국어 알림톡 템플릿 12종 (영어 · 중국어 · 일본어 · 베트남어 × 서명요청 · 리마인드 · 완료)

솔라피 콘솔 → 카카오 → 알림톡 템플릿에 **그대로 붙여 넣어** 심사를 신청하는 문구입니다.
한국어 템플릿(`docs/알림톡-템플릿-초안.md`)과 **구조 · 변수 · 버튼이 같습니다.**

> 🔴 **변수 이름은 한국어 그대로** 둡니다 (`#{이름}`, `#{문서명}` …). 받는 사람에게는 변수 이름이 보이지 않고 값만 보입니다.
> 코드(`supabase/functions/_shared/alimtalk.ts`)가 한국어 템플릿과 같은 변수 이름으로 값을 보내기 때문에, 이름을 번역하면 발송이 실패합니다.

> ⚠️ 카카오가 외국어 템플릿을 받아 주는지 공식 기준을 확인하지 못했습니다 (2026-10-25 검색 기준).
> **영어 「서명 요청」 1개를 먼저 신청**해 결과를 본 뒤 나머지를 신청하시면 반려 시 수정이 적습니다.
> 반려되더라도 서비스에는 문제가 없습니다 — 템플릿 ID가 없는 언어는 **자동으로 한국어 템플릿**으로 갑니다.

## 공통 등록 형태

| 항목 | 값 |
|---|---|
| 템플릿 유형 | 강조표기형 (한국어와 같음) |
| 카테고리 | 한국어 템플릿과 같은 항목 |
| 버튼 | 웹링크 1개 · **모바일 / PC 링크 둘 다** `https://intoedu.github.io/into-office/?s=#{서명토큰}` |
| 시간 | `#{기한}` · `#{완료일시}` 는 한국 시간으로 갑니다. 그래서 문구에 「Korea time」 등을 붙였습니다 |

### 승인 후 Supabase Secrets 에 넣을 이름

| | 영어 | 중국어 | 일본어 | 베트남어 |
|---|---|---|---|---|
| 서명 요청 | `ALIMTALK_TPL_REQUEST_EN` | `ALIMTALK_TPL_REQUEST_ZH` | `ALIMTALK_TPL_REQUEST_JA` | `ALIMTALK_TPL_REQUEST_VI` |
| 리마인드 | `ALIMTALK_TPL_REMIND_EN` | `ALIMTALK_TPL_REMIND_ZH` | `ALIMTALK_TPL_REMIND_JA` | `ALIMTALK_TPL_REMIND_VI` |
| 서명 완료 | `ALIMTALK_TPL_DONE_EN` | `ALIMTALK_TPL_DONE_ZH` | `ALIMTALK_TPL_DONE_JA` | `ALIMTALK_TPL_DONE_VI` |

값은 솔라피 템플릿 목록의 템플릿 ID (`KA01TP…`). 넣는 즉시 적용되며 재배포는 필요 없습니다.
(🔴 발신프로필 ID `KA01PF…` 와 헷갈리지 마세요)

### 언어는 어떻게 정해지나
- 서명 요청 만들기 2단계에서 서명자마다 **언어**를 고릅니다 (기본: 한국어).
- 그 언어의 템플릿 ID가 Secrets 에 있으면 그 언어 템플릿 · 그 언어 날짜 형식으로, 없으면 한국어로 갑니다.
- 서명 화면도 고른 언어로 열립니다 (서명자가 화면에서 직접 바꿀 수 있음).

## 참고 · 한계
- 번역은 원어민 검수를 받지 않았습니다. 가능하면 해당 언어 사용자에게 한 번 보여 주세요.
- 문서명 · 요청자 이름은 한국어로 입력한 그대로 들어갑니다 (예: 「기숙사 입사 동의서」).
- 법 조항 문구는 한국어 템플릿(이미 승인)의 문장을 옮긴 것입니다. 효력 범위에 대한 법률 검토는 별도로 받지 않았습니다.
- 가입 승인 템플릿은 회원(국내 사업자 · 개인)용이라 외국어 버전을 만들지 않았습니다.
