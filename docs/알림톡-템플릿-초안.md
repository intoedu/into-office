# 인투오피스 카카오 알림톡 템플릿 초안 4종

발송대행사(솔라피 등) 콘솔에 그대로 붙여 넣어 심사를 신청하면 되는 문구입니다.
채널 비즈니스 인증이 끝난 뒤 등록하시면 됩니다.

## 심사 통과를 위한 원칙

알림톡은 **정보성 메시지만** 허용됩니다. 아래 문구는 모두 그 기준에 맞춰 작성했습니다.

- 수신자의 행동(서명 요청 받음, 서명 완료, 가입 신청)에 따라 발송되는 안내입니다
- "지금 신청하세요", "이벤트", "할인", "무료" 같은 **광고성 표현을 쓰지 않았습니다**
- 변수는 `#{변수명}` 형식이며, 템플릿 등록 시 변수도 함께 등록해야 합니다
- 강조표기(제목)는 채널에 따라 지원 여부가 다르므로, 미지원 시 본문만 등록하세요

## 1. 서명 요청

**템플릿명**: `인투오피스_서명요청`
**분류**: 서비스 이용

```
[인투오피스] 전자서명 요청

#{이름}님, 안녕하세요.
#{요청자}님이 아래 문서에 대한 전자서명을 요청하였습니다.

▶ 문서명: #{문서명}
▶ 서명 기한: #{기한}

아래 버튼을 눌러 서명을 진행해 주세요.
본 전자서명은 「전자서명법」 제3조에 따라 서면 서명과 동일한 법적 효력을 가집니다.
```

**버튼**: 웹링크 · `서명하러 가기` · `#{서명링크}`

| 변수 | 예시 |
|---|---|
| `#{이름}` | 홍길동 |
| `#{요청자}` | 인투오피스 |
| `#{문서명}` | 2026년 재학생 개인정보 동의서 |
| `#{기한}` | 2026년 9월 5일 18:00 |
| `#{서명링크}` | https://.../?s=abc123 |

> 접근 암호를 설정한 문서라면 암호는 **이 메시지에 담지 마시고** 전화나 별도 문자로 전달하세요. 링크와 암호가 한 곳에 있으면 보안 효과가 사라집니다.

## 2. 서명 리마인드

**템플릿명**: `인투오피스_서명리마인드`
**분류**: 서비스 이용

```
[인투오피스] 전자서명 미완료 안내

#{이름}님, 안녕하세요.
요청드린 문서의 서명이 아직 완료되지 않아 다시 안내드립니다.

▶ 문서명: #{문서명}
▶ 남은 기간: #{남은기간}
▶ 서명 기한: #{기한}

기한이 지나면 링크가 만료되어 다시 요청해야 합니다.
이미 서명을 마치셨다면 본 안내는 무시하셔도 됩니다.
```

**버튼**: 웹링크 · `서명하러 가기` · `#{서명링크}`

| 변수 | 예시 |
|---|---|
| `#{이름}` | 홍길동 |
| `#{문서명}` | 용역 계약서 |
| `#{남은기간}` | 2일 |
| `#{기한}` | 2026년 9월 5일 18:00 |
| `#{서명링크}` | https://.../?s=abc123 |

## 3. 서명 완료

**템플릿명**: `인투오피스_서명완료`
**분류**: 서비스 이용

```
[인투오피스] 전자서명이 완료되었습니다

#{이름}님, 안녕하세요.
요청하신 문서의 모든 서명이 완료되었습니다.

▶ 문서명: #{문서명}
▶ 완료 일시: #{완료일시}
▶ 서명자: #{서명자목록}

서명이 완료된 문서와 감사추적인증서를 아래에서 확인하실 수 있습니다.
감사추적인증서에는 서명 시각, 접속 기록 등이 기록되어 문서의 진정성을 증명합니다.
```

**버튼**: 웹링크 · `문서 확인하기` · `#{문서링크}`

| 변수 | 예시 |
|---|---|
| `#{이름}` | 홍길동 |
| `#{문서명}` | 용역 계약서 |
| `#{완료일시}` | 2026년 9월 3일 14:20 |
| `#{서명자목록}` | 홍길동, 김철수 |
| `#{문서링크}` | https://.../?s=abc123 |

## 4. 가입 승인

**템플릿명**: `인투오피스_가입승인`
**분류**: 회원 관리

```
[인투오피스] 가입이 승인되었습니다

#{이름}님, 안녕하세요.
신청하신 인투오피스 계정이 승인되어 이용하실 수 있습니다.

▶ 아이디: #{아이디}
▶ 승인 일시: #{승인일시}

전자계약서 작성, 서명 요청, 문서 보관 기능을 바로 사용하실 수 있습니다.
문의사항은 서비스 내 「요청 · 문의」 메뉴를 이용해 주세요.
```

**버튼**: 웹링크 · `로그인하기` · `#{서비스링크}`

| 변수 | 예시 |
|---|---|
| `#{이름}` | 홍길동 |
| `#{아이디}` | intoedu |
| `#{승인일시}` | 2026년 9월 1일 10:00 |
| `#{서비스링크}` | https://intoedu.github.io/into-office/ |

## 등록 시 유의사항

1. **변수 등록을 빠뜨리지 마세요.** 본문에 `#{이름}`을 쓰면 템플릿 변수 목록에도 `이름`을 등록해야 합니다.
2. **대괄호 머리말**(`[인투오피스]`)은 채널명과 일치시키는 것이 심사에 유리합니다.
3. **반려되면 사유가 함께 옵니다.** 대부분 광고성 표현이나 변수 누락이므로, 해당 문구만 고쳐 재신청하면 됩니다.
4. **SMS 대체발송**을 켜두면 카카오톡 미설치자에게 문자로 전달됩니다. 이때 90byte를 넘으면 LMS로 과금되니, 대체문구는 짧게 작성하세요.

### SMS 대체문구 예시 (각 템플릿 공통)

```
[인투오피스] #{이름}님, 전자서명 요청이 도착했습니다. #{서명링크}
```

## 발송 시점 (인투오피스 연동 기준)

| 템플릿 | 발송 시점 | 연동 위치 |
|---|---|---|
| 서명 요청 | 문서 생성 직후 | `esign_create_document` / `esign_create_bulk` 성공 후 |
| 서명 리마인드 | 관리자가 리마인드 버튼을 누를 때 | `esign_send_reminder` |
| 서명 완료 | 마지막 서명자가 서명을 마쳤을 때 | `esign_submit_signature` 완료 처리 시 |
| 가입 승인 | 관리자가 회원을 승인할 때 | `esign_set_member_status` (status → active) |

발송은 Supabase Edge Function에서 대행사 API를 호출하는 방식으로 붙입니다.
API 키는 코드가 아닌 Supabase secrets에 보관해야 합니다.
