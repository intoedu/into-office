# INTO OFFICE

전자서명(전자계약) 웹 서비스. 계약서를 올리면 서명 요청 링크가 나가고,
서명이 끝나면 완료 PDF와 **감사추적 인증서**가 만들어집니다.

- 프론트엔드: `index.html` (단일 파일 SPA)
- 백엔드: Supabase (`esign` 스키마, ap-northeast-2 서울 리전)

## 화면

| 주소 | 화면 | 로그인 |
|---|---|---|
| `/` | 로그인 | — |
| `#pricing` | 요금 안내 | 불필요 |
| `#terms` | 이용약관 | 불필요 |
| `#privacy` | 개인정보처리방침 | 불필요 |
| `?s=<토큰>` | 서명 화면 | 불필요 |

## 데이터베이스

```
supabase/migrations/20260805000000_billing.sql   구독·요금제·사용량 (아직 미적용)
```

적용해도 `billing.settings.enforce_quota` 가 `false` 라 기존 동작은 바뀌지 않습니다.
활성화 절차는 파일 하단 주석과 결제 연동 가이드 4-6 참고.

## 오픈 전 반드시 할 일

1. **Supabase RLS 전수 점검** — publishable key는 공개되어도 되지만, RLS가 뚫려 있으면 남의 계약서가 노출됩니다
2. **Storage 버킷 `esign-docs` 접근 정책 확인** — public 이면 URL만으로 문서를 받을 수 있습니다
3. `index.html` 의 `BIZ_INFO` 를 실제 사업자 정보로 교체
4. 이용약관·개인정보처리방침 **변호사 검토**

자세한 내용은 [`docs/01-사업-시작-로드맵.md`](docs/01-사업-시작-로드맵.md) 4단계 참고.
